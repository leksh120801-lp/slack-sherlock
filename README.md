# 🕵️ Slack Sherlock

AI Workplace Investigator for Slack.

Slack Sherlock is an AI workplace investigator that searches Slack conversations in real time, connects external systems using MCP, and provides trusted, cited answers with actionable next steps.

## Features

- 🔎 Real-Time Slack Search
- 🤖 AI-powered summaries
- 🔗 MCP integrations
- 📚 Source citations
- ✅ Recommended next actions

## Tech Stack

- Slack Agent SDK
- Slack CLI
- TypeScript
- Node.js
- OpenAI / Claude / Gemini
- MCP
- Slack Real-Time Search API
